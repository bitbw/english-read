# English Read 推广渠道清单

> 除 [小红书](./小红书.md)、[知乎](./知乎.md) 外的推广方式汇总。  
> 在线体验：https://english-read.bitbw.top/

---

## 产品推广要点（各平台通用）

- **核心差异**：读英文 EPUB 原著 + 阅读中查词收录 + 艾宾浩斯间隔复习（不是孤立背单词 App）
- **钩子**：公共书库（哈利波特、小王子等）、免费 Web、手机浏览器可用
- **素材**：优先使用 `docs/screenshots/*-移动端.png` 竖屏截图
- **链接**：部分平台限外链，可用「主页链接 / 评论区置顶 / 搜索 English Read」

## 一、内容社区

| 平台 | 适合形式 | 说明 |
|------|----------|------|
| **V2EX** | 「分享创造」节点发介绍帖 | 开发者、早期用户多，接受工具站；标题直白，附 demo 链接 |
| **少数派 SSPAI** | Matrix 社区分享或投稿 | 偏效率工具，需突出「阅读工作流」而非单纯背词 |
| **豆瓣小组** | 英语阅读、原著、考研英语等小组 | 搜「英语阅读」「哈利波特 英文」相关组；先互动再发链接 |
| **贴吧** | 英语吧、哈利波特吧等 | 长尾搜索仍有流量，帖内附使用步骤 + 截图 |
| **微信公众号** | 自运营或找小号互推 | 适合长文教程：从选书 → 阅读查词 → 复习 → 统计 |

## 二、开发者 / 开源

| 方式 | 说明 |

## 三、垂直英语社群

| 渠道 | 说明 |
|------|------|
| **QQ / 微信群** | 四六级、雅思、原著阅读群；先答疑/分享方法，再介绍工具 |
| **Discord / Telegram** | 英文学习频道（留学生、海外用户） |
| **B 站** | 3–5 分钟录屏：公共书库选书 → 阅读查词 → 生词本 → 复习 → 学习统计 |
| **抖音 / 视频号** | 竖屏录屏 + 字幕，节奏快；标题突出「读原著顺便背单词」 |

### 视频脚本大纲（约 3 分钟）

1. 打开站点，登录 / 注册（10s）
2. 从公共书库加入《Harry Potter》并打开阅读（30s）
3. 选中单词，展示释义与「加入生词本」（40s）
4. 进入复习，展示闪卡与艾宾浩斯间隔（40s）
5. 打开学习统计、排行榜（30s）
6. 结尾：免费、浏览器可用、链接见简介/评论（10s）

## 七、各平台注意事项

| 注意项 | 说明 |
|--------|------|
| **外链限制** | 小红书、知乎、部分群组不允许或弱化外链；用置顶评论、个人简介、引导搜索 |
| **内容去重** | 同一主题多平台发时，改标题、开头和配图顺序，避免被判搬运 |
| **定位一致** | 强调「阅读场景里的词汇积累」，勿写成泛背单词 App |
| **数据反馈** | 每渠道记录 UV/注册量，2 周后只加码有效渠道 |
| **合规** | 注明免费、不收集多余信息；公共书库注意版权说明（用户上传 / 共享目录） |

## 八、推荐发布时间（学习类内容）

| 时段 | 时间 | 适用平台 |
|------|------|----------|
| 首选 | 工作日 12:00–13:00 | 小红书、知乎、公众号 |
| 次选 | 工作日 19:30–21:30 | 全平台；B 站晚间流量高 |
| 备选 | 工作日 7:30–8:30 | 小红书通勤刷帖 |
| 周末 | 10:00–11:30 或 20:00–22:00 | 规划学习、搜工具的用户更多 |

- 星期：**周二～周四** 通常优于周一、周五（学习类内容）
- 建议先发 1 条测 24h 数据，再决定是否同题材二发或换渠道
