# 公告系统 — 实现方案

## 1. 概述

在管理员后台增加公告管理功能，管理员可动态编辑系统公告内容、控制展示状态。公告内容以顶部横幅形式展示在应用主界面（`(app)/layout.tsx`），支持多语言。

### 核心需求

- 管理员在后台 CRUD 公告（标题、内容、状态、优先级）
- 公告在应用顶部展示，可关闭，可链接
- 支持多语言（zh / en）
- 支持多条公告同时存在，按优先级排序

## 2. 数据库设计

### 新表：`announcements`

在 `src/lib/db/schema.ts` 中新增：

```typescript
// ─────────────────────────────────────────────
// Announcements（系统公告）
// ─────────────────────────────────────────────

export const announcements = pgTable(
  "announcements",
  {
    id: text("id")
      .primaryKey()
      .$defaultFn(() => crypto.randomUUID()),
    /** 公告标题（zh） */
    titleZh: text("title_zh").notNull(),
    /** 公告标题（en） */
    titleEn: text("title_en"),
    /** 公告内容 Markdown（zh） */
    contentZh: text("content_zh").notNull(),
    /** 公告内容 Markdown（en） */
    contentEn: text("content_en"),
    /** 链接 URL（可选） */
    linkUrl: text("link_url"),
    /** 链接文字（zh），如 "查看详情" */
    linkLabelZh: text("link_label_zh"),
    /** 链接文字（en），如 "Learn more" */
    linkLabelEn: text("link_label_en"),
    /** 优先级（数字越大越靠前） */
    priority: integer("priority").notNull().default(0),
    /** 状态：draft | published | archived */
    status: text("status", { enum: ["draft", "published", "archived"] })
      .notNull()
      .default("draft"),
    /** 创建者 */
    createdBy: text("created_by")
      .notNull()
      .references(() => users.id, { onDelete: "cascade" }),
    /** 发布时间（为空则不展示） */
    publishedAt: timestamp("published_at", { mode: "date" }),
    /** 过期时间（过期后自动归档） */
    expiresAt: timestamp("expires_at", { mode: "date" }),
    createdAt: timestamp("created_at", { mode: "date" }).defaultNow().notNull(),
    updatedAt: timestamp("updated_at", { mode: "date" }).defaultNow().notNull(),
  },
  (t) => ({
    statusIdx: index("announcements_status_idx").on(t.status),
    priorityIdx: index("announcements_priority_idx").on(t.priority, t.status),
    publishedAtIdx: index("announcements_published_at_idx").on(t.publishedAt),
    createdByIdx: index("announcements_created_by_idx").on(t.createdBy),
  })
);

export const announcementsRelations = relations(announcements, ({ one }) => ({
  creator: one(users, { fields: [announcements.createdBy], references: [users.id] }),
}));
```

### Drizzle 迁移

```bash
npx drizzle-kit generate
npm run db:migrate
```

## 3. API 路由

### 3.1 管理员公告管理 API

路径：`src/app/api/admin/announcements/route.ts`

| 方法 | 用途 |
|------|------|
| `GET` | 获取全部公告列表（支持分页、状态筛选） |
| `POST` | 创建新公告 |

路径：`src/app/api/admin/announcements/[id]/route.ts`

| 方法 | 用途 |
|------|------|
| `GET` | 获取单条公告详情 |
| `PUT` | 更新公告 |
| `DELETE` | 删除公告 |

**响应格式示例（GET 列表）：**

```json
{
  "announcements": [
    {
      "id": "uuid",
      "titleZh": "系统维护通知",
      "titleEn": "Maintenance Notice",
      "contentZh": "系统将于...",
      "contentEn": "The system will...",
      "linkUrl": "/blog/maintenance",
      "linkLabelZh": "查看详情",
      "linkLabelEn": "Learn more",
      "priority": 10,
      "status": "published",
      "publishedAt": "2026-08-03T00:00:00.000Z",
      "expiresAt": null,
      "createdAt": "2026-08-03T00:00:00.000Z",
      "updatedAt": "2026-08-03T00:00:00.000Z"
    }
  ]
}
```

### 3.2 公开公告 API（给所有登录用户展示）

路径：`src/app/api/announcements/route.ts`

| 方法 | 用途 |
|------|------|
| `GET` | 获取当前有效的公告列表（`status = published` 且 `publishedAt ≤ now` 且（`expiresAt > now` 或 `expiresAt IS NULL`）），按 `priority DESC, publishedAt DESC` 排序 |

此路由使用 `requireSessionApi()`（普通登录即可），非管理员无需鉴权。

## 5. 组件设计

### 5.1 公告横幅 `AnnouncementBar`

- **位置**：`layout.tsx` 中 `Topbar` 下方、`main` 上方
- **行为**：
  - 使用 `useState` + `useEffect` + `clientFetch` 调用 `/api/announcements`
  - 每条公告显示为一个可关闭的横幅条
  - 关闭后存入 `localStorage`（标记 `announcement_closed_{id}`，24h 有效），不再重复展示
  - 如果有 `linkUrl`，显示为链接按钮
  - 支持多语言（标题和内容根据 `useLocale()` 切换）
- **样式**：蓝色/黄色/红色优先级配色，紧凑布局
- **状态处理**：
  - **Loading**：不显示占位符（避免布局抖动）
  - **Empty**：不渲染任何内容
  - **Error**：静默失败（不阻断页面）
  - **多条**：按优先级依次堆叠，可逐个关闭

### 5.2 管理员管理页 `AnnouncementManager`

- **位置**：`/admin/announcements`
- **功能**：
  - 表格展示所有公告（标题、状态、优先级、发布时间、操作按钮）
  - 创建/编辑公告的 Dialog 表单
  - 删除确认 Dialog
  - 状态切换按钮（发布/归档/草稿）
- **表单字段**：
  - 标题（zh / en，en 可选）
  - 内容（zh / en，Textarea，en 可选）
  - 链接 URL（可选）
  - 链接文字（zh / en，可选）
  - 优先级（数字输入，默认 0）
  - 状态（下拉选择：draft / published / archived）
  - 过期时间（日期选择器，可选）
- **状态处理**：
  - **Loading**：Skeleton 加载中
  - **Empty**：空状态提示 + 创建按钮
  - **Error**：错误提示卡片
  - **提交中**：按钮禁用 + loading 状态

## 8. 注意事项

- **公告内容不支持富文本**：使用纯文本 + 可选链接，保持简单
- **性能**：公告数量极少（通常 1-3 条），无需缓存策略
- **安全性**：管理员 API 使用 `requireAdminApi()`，公开 API 使用 `requireSessionApi()`
- **布局**：公告横幅位于 `Topbar` 下方、`main` 上方，不遮挡侧边栏
- **关闭持久化**：使用 `localStorage` + 24h 过期，避免用户每次刷新都看到已关闭的公告
- **静默失败**：公告加载失败不阻塞页面渲染，横幅空白即可
